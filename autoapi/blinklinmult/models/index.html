blinklinmult.models¶

Loading trained v2 models for inference, without the training stack.

BlinkCNN’s weights live in a Lightning checkpoint, but nothing about running one needs Lightning. Importing blinklinmult.train.module pulls in lightning, torchmetrics, h5py, omniloader and pandas – five packages an inference caller has no use for – so this module rebuilds the bare Module from the checkpoint’s own stored hyperparameters instead.

That is possible because the checkpoint is self-describing: save_hyperparameters stores model_config and train_config as plain dicts (deliberately, so weights_only=True loading works), and build_model can rebuild the network from them. The weights then load with zero missing and zero unexpected keys.

Published weights are stripped of optimizer and loop state before upload – 57 MB of Lightning checkpoint is only 19.1 MB of parameters – so load_checkpoint() accepts both shapes: a full training checkpoint from results/, and the slim published file.

blinklinmult.models.strip_checkpoint(checkpoint: dict[str, Any]) → dict[str, Any]¶

Reduce a training checkpoint to what inference needs.

Drops optimizer state, LR schedules, loop counters and callback state, all of which exist to resume training and are dead weight in a published artifact. On fw-focal-augment this takes 57 MB down to 19.1 MB.

Parameters:

checkpoint (dict[str, Any]) – A loaded Lightning checkpoint.

Returns:

{"state_dict", "hyper_parameters"} only.

Return type:

dict[str, Any]

Raises:

ModelLoadError – If either required key is absent.
